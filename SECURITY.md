# Security policy

Mods run inside your Claude Code session and can see and change tool calls, prompts and files. Treat installing one like installing any other code.

## Reporting a vulnerability

If a mod in this repository is malicious, leaks data, or can be abused, **do not open a public issue**. Report it privately through [GitHub's private vulnerability reporting](https://github.com/ibrahimkobeissy/claude-mods/security/advisories/new).

Please include the mod name, version, what it does wrong, and steps to reproduce. You'll get a reply within a few days, and a fix or removal will be published as soon as it's confirmed.

Vulnerabilities in Claude Code itself should be reported to Anthropic, not here.
